# Schools Folder

Each school gets its own folder using the school slug. Use `config.json` for brand overrides and per-school copy. Shared, reusable pages live in `Shared/`.

Example structure:

```
Schools/
  Shared/
    SchoolProfile.jsx
    RoleSelection.jsx
    SchoolLogin.jsx
    useSchoolConfig.js
  the-door-international-academy/
    config.json
  example-public-school/
    config.json
```
